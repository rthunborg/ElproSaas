- [x] [Review][Decision][Med] `A22` carries two contradictory gate statuses in the 9.4 sign-off register — `signed-off` (quote-terms row) and `blocking` (tax-wording row) — with no validator detecting the per-ID conflict — The same owning SoR ID `A22` is `signed-off (demo; real-pilot re-score)` at `pilot-fallback-cutover.md:1164` (quote terms) and `blocking` at `:1165` (tax wording, `A20`/`A21`/`A22`). Source: auditor@primary (M1+L1) + auditor@secondary (#3). Recommended: fix: scope the two rows so `A22` is not one ID with opposite gate statuses — split the tax-wording facet onto a distinct owning ID (e.g. a new `A22-tax` sub-ID, NOT reusing `A22`) OR add an explicit "facet:" qualifier column so quote-terms-`A22` (signed-off) and tax-wording-`A22` (blocking) are unambiguous; and add a per-ID status-coherence assertion to the 9.4 validator so a single ID cannot appear with both `signed-off` and `blocking`.
