### Blocking security defect

- **Fix now.** `admin_accept_membership_invitation` is executable by `authenticated` and is `SECURITY DEFINER`, but accepts caller-supplied `p_email`; it binds `auth.uid()` only to caller-supplied `p_user_id`, then compares the supplied email to the invite before assigning `auth.uid()` to the membership (`supabase/migrations/20260910165124_admin_user_management.sql:160-184`). A non-invitee possessing a valid membership ID and raw token can supply their own ID and the invitee email, thereby activate the invitee membership. The normal Next command derives identity from Auth (`src/server/commands/admin-users/accept-invitation.ts:19-51`), but direct RPC access bypasses it. Existing integration coverage proves the legitimate path only (`tests/integration/commands/admin-user-management.int.test.ts:40-74`). This confirms the NFR audit's Security FAIL finding (`_bmad-output/test-artifacts/nfr-assessment-epic-11.md`, “Security FAIL — direct invitation-acceptance RPC bypass”).

### Admin invitation lifecycle defects

- **Fix now.** Detail reads project an overdue invited row as `expired` (`src/features/admin-users/read.ts:55`), while the detail panel exposes resend/revoke only for literal `invited` (`src/components/admin-users/UserDetailPanel.tsx:24`). An administrator has no UI recovery action for the expired invitation.
- **Fix now.** Successful invitation acceptance returns `void` and neither renders success nor redirects/revalidates (`src/features/admin-users/actions.ts:16-19`; `src/app/(auth)/invite/accept/page.tsx:4`). The user remains on the activation form after the membership becomes active.
- **Fix now.** An uncertain delivery finalizes the persisted operation as `uncertain` (`src/server/auth/admin-user-service.ts:44-48`), while replay of that operation is rejected unless its outcome is `succeeded` (`src/server/commands/admin-users/invite.ts:30-34`). The open dialog retains its operation ID (`src/components/admin-users/UsersPage.tsx:10`), so retry cannot issue the required new attempt.
- **Fix now.** If provider delivery fails and finalizing the durable operation also throws, the catch block awaits the finalizer without containment (`src/server/auth/admin-user-service.ts:44-48`). The action rejects despite a prepared durable invitation, defeating its documented uncertain/reconciliation outcome.
