- **Whole app shell is a single client island.** `src/app/(app)/layout.tsx` delegates all chrome to a `"use client"` `AppShell`, shipping the sidebar/top-bar/inline-SVG icons as client JS and forfeiting App-Router server-layout streaming. Defensible for a small Phase A shell; revisit a server-layout + small client-nav-island split if the shell grows or when auth/tenant context lands (Epic 2). [src/app/(app)/layout.tsx:9-16, src/components/app-shell/AppShell.tsx:85]

This is an app-wide client-navigation focus concern (not unique to the drawer); address holistically (e.g. focus `#main-content` on route change) when route transitions / auth land. Owner: Epic 2 or a route-transition/a11y pass. [src/components/app-shell/AppShell.tsx:102-103]
- **Top-bar tenant/user region deferred to Epic 2 (owner decision 2026-06-16, resolved from code-review DN1).** UX §2 / the story Dev Notes envisioned neutral tenant/user placeholders in the slim top bar; the shell ships only the page-title region + empty primary-action slot (Task 1.1 scope). Tenant context + current user are populated by Epic 2 (tenant-admin login / tenant context resolution), so the placeholders land there rather than as churn-prone stubs now. Owner: Epic 2 (Story 2.1).
