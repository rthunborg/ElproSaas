## Acceptance Criteria

1. **Given** Phase A implementation stories are complete, **when** the acceptance-gate report is generated, **then** it **summarizes every Phase A gate** — clean install, typecheck, lint, unit tests, build, migration reset, command-integration tests, RLS/storage negative tests, golden-master comparisons, fixture-privacy checks — each marked **pass / fail / skipped-with-reason**, and a mandatory gate reported anything other than a real pass (skipped **without** a reason, or a false-green "pass" it did not actually run) **fails the report**. [Source: epics.md#Story 9.5 AC1; architecture.md#19 (the 10-stage gate list); .github/workflows/ci.yml (the real gate chain); test-design-epic-9.md 9.5-GATE-01 (P0, R-909), 9.5-EVID-01 (P1); PRD NFR32/37/38/39]
2. **Given** the report checks scope, **when** it scans the implemented surface, **then** it **CONFIRMS no deferred module leaked in** (Fortnox, supplier APIs, AI jobs, HR, rentals, assets/QR, DoU automation, tender/FKU RAG, full RBAC, customer portal, public privileged endpoints, broad admin analytics, broad document center) AND the scan **TRIPS on a seeded deferred-module token** — a positive test, not a mere omission. The scan is driven by the real `deferred-categories.ts` deny-list, never a hardcoded copy that drifts. [Source: epics.md#Story 9.5 AC2; test-design-epic-9.md 9.5-SCOPE-01 (P0, R-910), Non-Negotiable Requirements; project-context.md#Testing Rules (deferred-categories.ts deny-list); src/features/files/deferred-categories.ts]
3. **Given** the report checks readiness, **when** unresolved stop conditions remain, **then** it **lists them with named owner/accounting/legal/security decision owners** and **blocks real-pilot use where required** — reconciled 1:1 with the 9.4 sign-off register's `blocking` items (never a divergent copy). The demo track stays explicitly non-blocking (demo-data-only owner decision 2026-07-03). [Source: epics.md#Story 9.5 AC3 + Stop Conditions; test-design-epic-9.md 9.5-READY-01 (P2, R-920); docs/migration/pilot-fallback-cutover.md §4 (sign-off register); MEMORY (demo-data-only, tax sign-off deferred)]

**Non-AC hard constraints (epic blockers — hold regardless of numeric score):**
