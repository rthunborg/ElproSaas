### Key Insights And Patterns

Amelia (Developer): "Here's what stood out across all five stories and the epic-boundary review."

1. **The "trusted-recorded-state-over-reality" failure mode recurred in three different shapes this epic, all from the same root cause.** Story 5.1's resumed-run ATDD-skip trap, the missing `reorderSections` implementation behind an already-exported validator, and the epic-8a trace note's independent catch of a stale sprint-status entry are the same underlying bug: an artifact (code scaffold, tracking file, prior-run claim) recorded a state that had since drifted, and a later phase almost trusted it. This is the third epoch running a version of this pattern is caught (Epic 3: stale planning doc; Epic 4: stale story Dev Notes claim; Epic 5: resumed-run scaffolds + tracking state) — it is now a structural feature of resumed/multi-session work, not a one-off mistake.

2. **The `pnpm audit` CI gate is now a four-epic-carried CONCERNS despite an explicit owner assignment and an explicit "no fourth carry" commitment at the Epic 4 retro.** This is the single clearest finding of this retrospective: a CONCERNS-level NFR item that has an owner and a stated deadline STILL didn't land, because nothing in the actual pipeline forced the question back with a hard consequence — it was re-stated as advisory prose in the NFR report again. Naming an owner was necessary but not sufficient.

3. **Fold-forward of review lessons is working.** Epic 4's fallback-fabrication lesson was explicitly folded into the review checklist per that retro's action item, and this epic's review caught the *exact* shape of bug (null-cost fail-open masquerading as 100% margin) it was designed to catch. This is evidence the review-checklist-fold-forward mechanism has real teeth, not just documentation value.

4. **Frozen-snapshot-by-copy is now a three-times-proven discipline** (Epic 3 snapshot contract → Epic 4 golden fixture freeze → Epic 5 pricing-source row freeze), each time behaviorally proven (mutate-after-capture tests), not just structurally asserted. This is the load-bearing guarantee Epic 6's immutable sent-quote-version needs, and it is demonstrably solid going in.

5. **Owner/accounting/legal sign-off questions remain a growing, not shrinking, backlog.** What started as 8 items after Epic 4 has not been resolved by a real working session; Epic 5 adds calc-specific items (inclusion pin, blocker/warning split, new-version copy, non-final tax wording) to the same "engine ships it unapproved, decision still pending" pile. Non-blocking today because the engine is conservative by construction, but the pile is not being worked down — Epic 6 (sending real quotes) is the point where these need actual answers, not another "carry forward."
