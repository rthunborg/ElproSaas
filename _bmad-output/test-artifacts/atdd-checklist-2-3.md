  (UNAUTHENTICATED / TENANT_MEMBERSHIP_REQUIRED / VALIDATION_FAILED /

- `audit-append-only.int.test.ts` — app-path UPDATE/DELETE denied (assert mechanism,

- `audit-anon-isolation.int.test.ts` — anon cannot SELECT/INSERT audit; anon has NO

- `record-audit-event-search-path.int.test.ts` — DEFINER hijack proof + control
  (CONDITIONAL: delete if dev-story documents the GRANT/policy combo alone as the
  enforcement and adds no DEFINER fn).

### Red-phase mechanism (keeps gates GREEN today)
- **Unit files** use `node --test` per-test `{ skip: "RED: …" }`. The not-yet-built
  `@/server/commands/*` modules are loaded via **dynamic `import()` inside each skipped
  body** (a static import would crash file load before `{ skip }` applies). Result: 17
  skipped, 0 failed.
- **Integration files** are `describe.skip(...)`. Modules + the future
  `tests/factories/audit-events` helper are loaded **dynamically inside the skipped `it`
  bodies**; the two seeding suites tolerate the missing factory in their top-level
  `beforeAll` (which runs even under `describe.skip`). Result: 21 skipped, 0 failed.
- **typecheck + lint:** the two scaffold globs (`tests/unit/server/commands/**`,
  `tests/integration/commands/**`) are excluded in `tsconfig.json` and `eslint.config.mjs`
  — mirroring the existing `tests/e2e/**` precedent for scaffolds that reference an
  un-landed runner/module. `@ts-nocheck` headers suppress editor noise. **dev-story
  removes both excludes + the `@ts-nocheck`/`{ skip }`/`describe.skip` markers as it
  implements, re-enrolling each suite into the gates as it flips GREEN.**
